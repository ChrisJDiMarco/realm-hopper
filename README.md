# Realm Hopper 2.0

Realm Hopper is an original top-down crossing game for macOS. Ten authored expeditions expand from 3 to 20 moving hazard layers, with three simultaneously simulated vertical realms: Depths, Surface, and Sky.

Version 2.0 adds rechargeable dashes, altitude energy, checkpoints, shifting lane patterns, wind and current forces, moving golden flies, near-miss scoring, level medals, weather systems, realm radar, danger telegraphs, persistent best scores, richer champion celebrations, and upgraded visual/audio feedback.

## Controls

- `WASD` or arrow keys — hop
- `Q` — dive one realm
- `E` — rise one realm
- `Space` — dash two spaces
- `P` or `Escape` — pause
- Click Morn / Noon / Night (or press `1` / `2` / `3`) to change the world lighting

Collect every rune (some are in other realms) and reach the winner circle. Powerups include shield, time freeze, double score, bubble armor, and wings.

## Run from source

```sh
npm install
npm start
```

## Package for Apple silicon

```sh
npm run package:mac
```
